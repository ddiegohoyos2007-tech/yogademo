# Estudio Mareas — sitio de ejemplo

Landing page de una sola página (HTML + CSS + JS sin dependencias) para un estudio de pilates y yoga.

- Abre `index.html` en el navegador o publícalo en GitHub Pages / Netlify.
- Enlace de WhatsApp: variable `WA` al inicio del `<script>`.
- Horarios y cupos: objeto `SCHEDULE` en el mismo script.
